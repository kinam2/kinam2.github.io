# 7. There is a book — potthako hoti

지금까지는 '이다·있다'를 빼고 말해 왔습니다. 이번 과에서 드디어 문장의 중요한 부분인 **동사**(verb)가 등장합니다. 그중 가장 흔한 동사, '**이다·있다**'부터 시작합니다.

## 1. 짧은 결론

7과는 **동사 입문**이고, 'to be' 동사 세 개의 현재형을 배웁니다. 핵심은 세 가지예요.

> **Pāli는 '있다·~이다'를 보통 hoti, bhavati, atthi 세 동사로 말한다. 대부분의 문맥에서 서로 바꿔 쓸 수 있다.** 〔교재〕

> **동사는 주어의 인칭(1·2·3)과 수(sg./pl.)에 맞춰 변한다. 주어의 성(gender)은 상관하지 않는다.** 〔교재〕

> **사전에 실린 꼴은 '현재·3인칭·단수·능동태'다. 다른 경우에는 활용(conjugation)을 알아야 한다.** 〔교재〕

---

## 2. 쉬운 설명

**동사 'to be'가 하는 일:** 무언가가 **존재한다**(있다), 또는 어떤 **성질을 가진다**(~이다)고 말합니다. 앞의 것은 영어 'there is/are'에, 뒤의 것은 'be, become'에 해당합니다. hoti, bhavati, atthi는 경전에서 가장 자주 쓰이는 동사들입니다. 〔교재〕

(교재 주: 두 말을 이어 주기만 하고 자체 내용은 없는 동사를 언어학에서 copula [계사]라고 부릅니다.)

**활용(conjugation)이란?** 명사가 격에 따라 꼴을 바꾸듯(곡용), 동사도 쓰임에 따라 꼴을 바꿉니다. 이것을 활용이라고 합니다. 〔교재〕

```
동사 활용에서 따지는 네 가지
├─ 시제/법 (tense/mood)
│   ├─ 시제: 현재, 과거, 미래
│   └─ 법:   명령법, 원망법(optative), 조건법
├─ 인칭 (person):  1인칭, 2인칭, 3인칭  ← 6과 인칭대명사와 짝
├─ 수 (number):    단수, 복수
└─ 태 (voice):     능동태, 중간태(middle)  ← 지금은 능동태만
```
〔교재〕

(교재 주: 전통적으로는 과거 시제가 셋이라 시제·법이 모두 여덟 가지입니다. 하지만 널리 쓰이는 과거는 하나뿐이고, 나머지 둘은 옛 흔적으로 드물게 보입니다.)

**비유 (문법 설명 아님):** 동사는 주어와 악수하는 손입니다. 상대가 몇 명인지(수), 누구인지(나·너·그, 인칭)에 따라 손 모양을 바꾸지만, 상대가 남자인지 여자인지(성)는 보지 않습니다.

## 3. 단계별 분석

### (a) 'to be' 동사 현재형 — Table 7.1

〔교재 Table 7.1〕

| 동사 | 인칭 | sg. | pl. |
|---|---|---|---|
| **hoti** | 3인칭 | hoti | honti |
| | 2인칭 | hosi | hotha |
| | 1인칭 | homi | homa |
| **bhavati** | 3인칭 | bhavati | bhavanti |
| | 2인칭 | bhavasi | bhavatha |
| | 1인칭 | bhavāmi | bhavāma |
| **atthi** | 3인칭 | **atthi** | **santi** |
| | 2인칭 | **asi** | **attha** |
| | 1인칭 | **amhi / asmi** | **amha / asma** |

atthi는 꼴이 불규칙하니 특히 주의하세요(굵은 글씨). 〔교재〕

관찰 몇 가지 〔추론〕:
- hoti와 bhavati는 **어미가 같은 줄**을 탑니다: 3인칭 -ti / -nti, 2인칭 -si / -tha, 1인칭 -mi / -ma. 이 어미 한 벌만 익히면 두 동사를 다 활용할 수 있습니다.
- bhavati의 1인칭은 어미 앞 모음이 길어집니다(bhavāmi, bhavāma).
- 표의 아래쪽(1인칭)은 6과 대명사와 짝입니다: ahaṃ … homi, mayaṃ … homa.

**PD에서 만나는 asmi:** 5과 (g)에서 본 esohamasmi = eso aham asmi의 **asmi**가 바로 atthi의 1인칭 단수입니다. PD는 aham asmi를 '나라는 느낌'으로 풀고 asmi māna와 연결합니다.〔PD〕[^pd1]

### (b) "책이 있다" 만들기

```
"책이 있다"  단수
  potthako / potthakaṃ  hoti.
  potthako / potthakaṃ  bhavati.
  potthako / potthakaṃ  atthi.

"책들이 있다"  복수
  potthakā(ni)  honti / bhavanti / santi.
```
〔교재〕

3과에서 배운 potthako hoti가 여기서 정식으로 설명됩니다. 주어가 3인칭이므로 동사도 3인칭입니다.

### (c) 동사는 성을 상관하지 않는다 — "아름다운 소녀가 있다"

이제부터 교재는 hoti만 씁니다. 〔교재〕

```
surūpā kaññā hoti.      아름다운 소녀가 있다
kaññā hoti surūpā.      (같은 뜻, 어순만 다름)
hoti kaññā surūpā.      (같은 뜻, 동사를 앞으로)
├─ surūpā  형용사 f. nom. sg.  ← kaññā에 맞춤 (4과)
├─ kaññā   명사   f. nom. sg.
└─ hoti    동사   3인칭 sg.    ← 성과 무관, 3인칭·단수만 맞춤
```

### (d) 어순이 바꾸는 뜻 — "소녀가 아름답다"

```
kaññā surūpā hoti.      소녀가 아름답다
└─ surūpā가 kaññā와 hoti 사이 → 보어('아름답다')로 읽힘
```

뜻이 조금 달라집니다. (c)는 "아름다운 소녀가 **있다**"(존재), (d)는 "소녀가 **아름답다**"(성질)입니다. 〔교재〕 5과 (f)에서 본 "어순이 뜻을 정리한다"와 같은 교훈입니다.

### (e) 관사가 없으니 ta로 — "그 소녀는 아름답다"

Pāli에는 관사(a, the)가 없습니다. 특정한 대상을 가리키려면 5과의 대명사적 형용사 **ta**를 씁니다. 〔교재〕

```
sā kaññā surūpā hoti.               그 소녀는 아름답다
tā kaññā(yo) surūpā(yo) honti.      그 소녀들은 아름답다
   └ 복수: 대명사·명사·형용사·동사가 모두 복수로
```

### (f) 1·2인칭 주어 — 동사도 인칭을 맞춘다

```
ahaṃ thūlo puriso homi.            나는 뚱뚱한 남자다
mayaṃ thūlā purisā homa.           우리는 뚱뚱한 남자들이다
tvaṃ paññavatī taruṇā itthī hosi.  너는 지혜로운 젊은 여인이다
tvaṃ itthī hosi paññavatī taruṇā.  (더 문체적인 어순)
tumhe paññavatī itthī/itthiyo hotha.  너희는 지혜로운 여인들이다
```
〔교재〕

한 문장만 뜯어 봅니다.

```
tvaṃ paññavatī taruṇā itthī hosi.
├─ tvaṃ       2인칭 sg. (성 없음, 6과)
├─ paññavatī  형용사 f. nom. sg.  ← -vantu 부류의 여성형 (4과 (d) dhanavatī와 같은 꼴)
├─ taruṇā     형용사 f. nom. sg.  ← 듣는 이의 실제 성별을 따름 (6과 (e))
├─ itthī      명사   f. nom. sg.
└─ hosi       동사   2인칭 sg.    ← tvaṃ에 맞춤
```

paññavatī가 -vantu 부류라는 점은 교재가 직접 말하지 않습니다. dhanavantu → dhanavatī와 같은 모양이라 그렇게 본 것입니다.〔추론〕

### (g) 동사를 빼도 되지만, 지금은 넣자

앞의 장들에서 보았듯이, 뜻이 분명하면 'to be' 동사는 생략할 수 있습니다. 하지만 교재는 익숙해질 때까지 **직접 만드는 문장에는 동사를 넣으라**고 권합니다. 〔교재〕

## 4. 다시 공부할 포인트

- **꼭 외울 것:** Table 7.1. 특히 불규칙한 atthi: atthi / santi, asi / attha, amhi·asmi / amha·asma. 〔교재〕
- 어미 한 벌: -ti / -nti, -si / -tha, -mi / -ma (hoti, bhavati 공통). 〔추론〕
- 동사는 주어의 **인칭·수**에 맞추고, **성은 보지 않는다**. 〔교재〕
- 사전형 = 현재·3인칭·단수·능동태. 〔교재〕
- 어순: surūpā kaññā hoti(아름다운 소녀가 있다) vs kaññā surūpā hoti(소녀가 아름답다). 〔교재〕
- 관사가 없으니 '그 ~'는 ta로: sā kaññā. 〔교재〕
- **미루기 OK:** 과거·미래 시제, 명령·원망·조건법, 중간태.

### 연습문제 7

다음을 Pāli로 말해 보세요. 동사 hoti를 넣어서요. 〔교재 Exercise 7〕

```
1. 모차르트는 위대한 음악가다.
2. 우리는 힘 있고 부유한 상인들이다.
3. 너희는 늙고, 쇠약하고, 가난한 거지들이다.
4. 나는 물소다. 나는 검고, 크고, 사납다.
5. 너는 작은 곤충이다. 너는 못생기고, 보잘것없고, 쓸모없다.
```
