# 6. It (is) a book — so potthako

5과에서 "이것·그것·저것"을 배웠다면, 이번 과는 **"나·너·그"**, 곧 대화에 참여하는 사람을 가리키는 말을 배웁니다.

## 1. 짧은 결론

6과는 **인칭대명사**(personal pronoun) 입문입니다. 핵심은 세 가지예요.

> **ta는 두 가지 역할을 한다. 5과의 지시대명사이면서, 이번 과의 3인칭 대명사('그·그녀·그것·그들')이다.** 〔교재〕

> **1인칭(amha)과 2인칭(tumha)은 성 구별이 없다. 하지만 그 사람을 꾸미는 형용사는 실제 성별을 따른다.** 〔교재〕

> **짧은 꼴 no, vo (뒤에 나올 me, te 포함)는 문장 맨 앞에 오지 않고, 거의 언제나 바로 앞 단어에 걸린다. 처음에는 쓰지 말고 눈에 익히기만 하자.** 〔교재〕

---

## 2. 쉬운 설명

**인칭(person)이란?** 여기서 '인칭'은 사람(인간)이라는 뜻이 아닙니다. **대화에 참여하는 자리**를 나누는 문법 범주예요. 〔교재〕

```
인칭 = 대화 속 자리
├─ 1인칭  말하는 사람        나, 우리       amha
├─ 2인칭  듣는 사람          너, 너희       tumha
└─ 3인칭  이야기되는 대상    그, 그녀, 그것, 그들   ta
```

(교재 주: 전통 문법서에서는 1인칭과 3인칭의 순서가 반대입니다. 교재는 전통 순서를 따르지 않습니다.)

**비유 (문법 설명 아님):** 연극 무대를 떠올려 보세요. 대사를 말하는 배우(1인칭), 그 대사를 듣는 상대 배우(2인칭), 두 사람이 이야기하는 무대 밖의 누군가나 무언가(3인칭). 역할은 '사람'이 아니라 **무대 위의 자리**로 정해집니다. 그래서 3인칭에는 책 같은 물건도 들어갑니다.

---

## 3. 단계별 분석

### (a) 인칭대명사 주격 — Table 6.1

〔교재 Table 6.1〕

| 대명사 | sg. | pl. |
|---|---|---|
| **amha** (1인칭) | ahaṃ | mayaṃ / no |
| **tumha** (2인칭) | tvaṃ / tuvaṃ | tumhe / vo |

| 대명사 | m. sg. | m. pl. | f. sg. | f. pl. | nt. sg. | nt. pl. |
|---|---|---|---|---|---|---|
| **ta** (3인칭) | so | te | sā | tā | taṃ | tāni |

- 1·2인칭은 모든 성에서 같은 꼴이라 한 번만 적었습니다. **성이 없는 것**으로 볼 수도 있습니다. 〔교재; Collins 2005〕
- ta 행은 5과 Table 5.1과 똑같습니다. 〔교재〕
- 이 표의 꼴은 모두 외워야 합니다. 〔교재〕

### (b) 짧은 꼴(enclitic) no, vo — 지금은 알아보기만

1·2인칭에는 아주 흔한 **짧은 꼴**이 있습니다. no(우리), vo(너희)이고, 뒤의 장에서 me, te도 나옵니다. 〔교재〕

이 짧은 꼴은 다른 뜻으로도 널리 쓰여서 헷갈리기 쉽습니다. 실제 규칙은 이렇습니다. 〔교재; Warder 2001〕

- 구나 절의 **맨 앞에 오지 않는다.**
- 거의 언제나 **바로 앞 단어**에 걸린다.

```
gāmaṃ no gaccheyyāma.   우리 마을에 가자
├─ gāmaṃ        마을을
├─ no           우리 (짧은 꼴, 맨 앞이 아니라 둘째 자리)
└─ gaccheyyāma  가자
```

(교재 주: 전통 문법가 Aggavaṃsa도 *Saddanīti*에서 "te, me, vo, no는 다른 단어 뒤에 온다"고 적었습니다.)

교재의 권고: 처음에는 짧은 꼴을 **쓰지 말고**, 충분히 많이 본 뒤에 쓰임을 익히세요. 〔교재〕

### (c) "그것은 책이다" 만들기

5과의 지시대명사와 만드는 법이 같습니다. ta가 가리키는 명사의 성·수를 따라갑니다. 〔교재〕

```
"그것은 책이다"  단수
  m.  so   potthako.
  nt. taṃ  potthakaṃ.

"그것들은 책이다"  복수
  m.  te    potthakā.
  nt. tāni  potthakāni.
```

### (d) 5과와 이어 보기 — "이 책은 크다. 그것은 무겁다."

```
(yo) ayaṃ potthako thūlo, so garuko.        m.
(yaṃ) idaṃ potthakaṃ thūlaṃ, taṃ garukaṃ.   nt.
├─ ayaṃ / idaṃ   ima  ← 지금 가리키는 책 (5과)
├─ thūlo / thūlaṃ      보어 '크다'
├─ so / taṃ      ta   ← 앞에서 말한 그 책을 다시 받음 (3인칭)
└─ garuko / garukaṃ    보어 '무겁다'
```

괄호 속 yo / yaṃ은 관계사 ya('~인 것')입니다. 교재는 이런 문장을 ya–ta 구조로 만드는 편이 더 낫다고 하며, 16과에서 다룹니다. 〔교재〕

### (e) "나는 노인이다. 너는 어린 소녀다." — 형용사는 실제 성별을 따른다

```
ahaṃ mahallako puriso.   나는 늙은 남자다
├─ ahaṃ       amha  1인칭 sg. (성 없음)
├─ mahallako  형용사 m. nom. sg.
└─ puriso     명사 m. nom. sg.

tvaṃ taruṇā kaññā.       너는 어린 소녀다
├─ tvaṃ       tumha 2인칭 sg. (성 없음)
├─ taruṇā     형용사 f. nom. sg.  (taruṇa → a→ā, 4과 Table 4.1)
└─ kaññā      명사 f. nom. sg.
```

ahaṃ, tvaṃ 자체에는 성이 없지만, 거기에 붙는 형용사는 **말하는 사람과 듣는 사람의 실제 성별**을 따릅니다. 그래서 명사를 빼고 말해도(남자가 여자에게 말하는 상황) 이렇게 됩니다. 〔교재〕

```
ahaṃ mahallako.  tvaṃ taruṇā.
     └ m. (말하는 남자)   └ f. (듣는 여자)
```

### (f) 성이 하나뿐인 명사는 어떻게 하나 — "그녀는 요리사다"

kumāra / kumārī(소년/소녀)처럼 두 성의 꼴을 가진 단어도 있지만, 많은 단어는 성이 하나뿐이고 대부분 남성입니다. 예를 들어 sūda(요리사)는 m.입니다. 그럼 "그녀는 요리사다"는 어떻게 말할까요? 〔교재〕

교재 저자는 전통 관점에서 분명한 해법을 찾지 못했다고 말합니다. 두 가지 길을 생각해 볼 수 있습니다. 〔교재〕

```
"그녀는 요리사다"
├─ 길 1: 여성형 새 단어 만들기
│   └─ sūdā, sūdakā, sūdakārinī, (더 나은) bhojanakārinī
│      단점: 어휘가 늘고, 다른 사람이 받아들이기까지 시간이 걸림
└─ 길 2: 성이 어긋난 채로 쓰기
    └─ sā sūdo hoti.   (sā f. + sūdo m.)
```

(교재 주: 길 2 같은 쓰임을 전통에서는 **vikatikattā**라 부르고, 영어 문법의 주격 보어(subject complement)에 해당합니다. 어색해 보여도 문법적으로 맞습니다. sā mātugāmo gacchati "그녀, 한 여인이 간다"는 동격(apposition)인데, mātugāma가 남성 명사라 다른 방법이 없습니다. 다만 교재 저자는 이 용례를 경전에서 찾지 못했습니다. 성이 어긋나는 일은 숫자를 쓸 때(25과)나 게송에서도 일어납니다. 예: pamādo maccuno padaṃ [Dhp 21] "방일은 죽음의 길이다", pamādo m. + padaṃ nt.)

### (g) atta — 재귀대명사 '자기 자신'

인칭대명사 말고도 **atta**는 재귀대명사 **자기 자신**으로 쓰입니다. 〔교재; Warder 2001〕 atta는 불규칙하게 변화합니다(교재 부록 B). 〔교재〕

교재는 이 부분이 아직 어렵다면 **훑어만 보라**고 합니다. 나중에 다시 볼 참고용입니다. 〔교재〕

```
attānaṃ sukheti pīṇeti                 [DN 29]
  자기 자신을 행복하게 하고, 기쁘게 한다
attanāva attānaṃ byākareyya            [DN 16]
  자기 자신에 의해 자기 자신을 설명해야 한다
jānāsi, āvuso korakkhattiya, attano gatiṃ?   [DN 24]
  벗 Korakkhattiya여, 그대 자신의 gati를 아는가?
```

**PD 관점 한 줄:** PD는 attā에 두 가지 뜻이 있다고 봅니다. 일상적인 뜻은 '사람·자기 자신'이고, 더 깊은 뜻은 '통제할 수 있는 것, 실질[이로움]이 있는 것'입니다. 어느 뜻인지는 **문맥이 정합니다.** 위 예문들의 atta는 일상적인 뜻 '자기 자신'에 해당합니다. 반면 5과 (g)의 eso me attā나 Tilakkhaṇa의 anatta는 깊은 뜻 쪽입니다.〔PD〕[^pd1][^pd2]

### (h) '자기의'를 뜻하는 다른 말들

몇몇 형용사도 같은 뜻으로 쓰입니다: **sa, saka, nija, niya, niyaka**. 재귀 용법으로는 **sayaṃ**(스스로), **sāmaṃ**(몸소)도 흔합니다. 〔교재; Perniola 1997〕

```
nisinno ahaṃ sake āsane.               [MN 82]
  나는 내 자리에 앉았습니다            ← saka
sehi kammehi dummedho, aggidaḍḍhova tappati.   [Dhp 136]
  어리석은 이는 자기 업들로, 불에 덴 듯 괴로워한다   ← sa
sayaṃkataṃ makkaṭakova jālaṃ           [Dhp 347]
  거미가 스스로 만든 그물에 (걸리듯)   ← sayaṃ
```

교재 예문은 이 밖에도 DN 23, DN 27, Jātaka, Therīgāthā에서 뽑은 것이 더 있습니다. 지금 다 이해하지 못해도 괜찮습니다. 〔교재〕

[^pd1]: Pure Dhamma, "Anattā in Anattalakkahana Sutta – No Soul or an Ātma". <https://puredhamma.net/key-dhamma-concepts/anicca-dukkha-anatta-2/anatta-systematic-analysis/anatta-no-soul-no-atma>
[^pd2]: Pure Dhamma, "'Attā' as 'Self' – Wrong Translation in Many Suttās". <https://puredhamma.net/is-there-a-self/atta-as-self-wrong-translation-in-natumhaka-sutta>. 이 글은 많은 영어 번역이 attā를 언제나 일상적 뜻('self')으로만 옮겨 혼란이 생긴다고 지적합니다.

## 4. 다시 공부할 포인트

- **꼭 외울 것:** ahaṃ / mayaṃ, tvaṃ (tuvaṃ) / tumhe, 그리고 5과의 ta 주격. 〔교재〕
- 인칭은 '사람'이 아니라 **대화 속 자리**: 1인칭 말하는 이, 2인칭 듣는 이, 3인칭 이야기되는 대상. 〔교재〕
- ta = 지시대명사이자 3인칭 대명사. 〔교재〕
- 1·2인칭은 성이 없지만, 붙는 형용사는 **실제 성별**을 따른다: ahaṃ mahallako / tvaṃ taruṇā. 〔교재〕
- 짧은 꼴 no, vo (me, te)는 맨 앞에 오지 않고 바로 앞 단어에 걸린다. 지금은 알아보기만. 〔교재〕
- **미루기 OK:** atta의 불규칙 변화(부록 B), sa/saka/sayaṃ 예문, ya–ta 구조(16과), 숫자의 성 불일치(25과).

### 연습문제 6

다음을 Pāli로 말해 보세요. 〔교재 Exercise 6〕

```
1. 너희는 사악하고 큰 적들이다.
2. 너는 키 크고 잘생기고 영리한 남자다.
3. 우리는 위대한 군대다, 강하고 용감한.
4. 그 사람들은 불교 비구들이다. 그들은 마르고 약하다.
5. 이 물건은 귀하다. 그것은 푸른 타원형 보석이다.
```
