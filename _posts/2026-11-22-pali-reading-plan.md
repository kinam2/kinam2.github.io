# 『Pāli for New Learners』 기반 Pāli 독해 학습 계획

> 이 문서는 J. R. Bhaddacak, 『Pāli for New Learners』 Version 3.0의 **내용이 아닙니다.** 교재의 장·부록 구성을 바탕으로 **따로 정리한 독해 학습 계획**입니다. 교재에서 가져온 것은 장 번호·장 제목·부록 목록·일부 예문이고, 학습 원칙·로드맵의 단계 구분·독해 절차·훈련 문항·진단표는 정리자가 만든 것입니다.

## 0. 문서의 목적

목표는 문법 용어를 많이 아는 것이 아니라, 실제 Pāli 문장을 읽을 때 다음 일을 할 수 있게 되는 것이다.

1. 단어를 알아본다.
2. Sandhi가 있으면 원형을 복원한다.
3. 합성어가 있으면 가능한 만큼 분해한다.
4. 형태를 분석한다.
5. 문장 안에서 기능을 찾는다.
6. 직역한다.
7. 자연스러운 번역으로 정리한다.
8. 복수 해석이 가능하면 대안을 제시한다.

## 1. 기본 원칙

### 1.1 의미를 먼저 본다

초보자는 문법 이름보다 먼저 뜻을 잡는다.

- bhikkhussa → "승려의" → 그다음에 genitive singular

처음부터 "genitive singular masculine"이라고 설명하면 독해보다 암기가 앞서게 된다.

### 1.2 문법은 독해 절차 안에서 배운다

- dhammaṃ → "dhamma가 목적어처럼 쓰였구나."
- bhikkhussa → "bhikkhu와 관련된 소유·관계 표현이구나."
- gacchati → "누군가 간다."

### 1.3 변화표는 참고용이다

부록 B(명사 변화표)와 부록 C(동사 변화표)는 필요할 때 찾아보는 자료다. 초보 단계에서는 표 전체를 외우기보다 자주 보이는 형태부터 익힌다.

- buddho → "Buddha가 주어처럼 쓰였구나."
- buddhaṃ → "Buddha가 목적어처럼 쓰였구나."
- buddhassa → "Buddha의 / Buddha에게 관련된 말이구나."

### 1.4 전통 문법 용어는 교재가 다루는 자리에서 배운다

Kāraka는 교재 38장(Cases Summarized)에서, Kita는 32·33장(수동·사역)과 부록 H에서, Taddhita·Paccaya·어근은 부록 I·J·K에서 다룬다. 격과 동사의 기본 뜻에 익숙해진 뒤 해당 장에서 만나면 된다.

### 1.5 모든 설명은 독해로 돌아온다

> 그래서 이 문장을 어떻게 읽는가?

## 3. 추천 학습 로드맵

교재는 1장부터 차례로 읽도록 짜여 있다. 아래 단계는 그 순서를 지키면서 **무엇에 집중할지**를 묶은 것이다.

### 3.1 1단계: 문자와 아주 쉬운 문장 (2–7장)

- Pāli 표기와 발음을 익힌다.
- 명사·형용사·대명사의 기본 형태를 본다.
- hoti / atthi와 그 복수형을 읽는다.
- "A가 있다", "A는 B이다" 수준의 문장을 이해한다.

대표 문장 (교재 3·7장)

- potthako hoti. / potthako atthi. → 책이 있다.

### 3.2 2단계: 격의 의미 익히기 (8–15장)

격 이름보다 의미를 먼저 잡는다.

| 의미 | 대표 격 | 쉬운 뜻 | 교재 |
|---|---|---|---|
| 누가? | nominative | 주어 | 3장 |
| 누구를? 무엇을? 어디로? | accusative | 목적어 / 방향 | 10장 |
| 누구의? | genitive | 소유 / 관계 | 8장 |
| 누구에게? 무엇을 위해? | dative | 대상 / 목적 | 13장 |
| 어디에서부터? 무엇 때문에? | ablative | 출발점 / 이유 | 11장 |
| 무엇으로? 누구와? | instrumental | 수단 / 동반 | 12장 |
| 어디에? 언제? | locative | 장소 / 시간 | 14장 |
| 부름 | vocative | "오, …" | 15장 |

불규칙 명사(9장)는 이 단계에서 한 번 훑고, 부록 B와 함께 필요할 때 다시 본다.

대표 문장

- bhikkhu dhammaṃ suṇāti. → 승려가 가르침을 듣는다.
- buddhassa sāvako. → Buddha의 제자.
- gāmamhā āgacchati. → 마을에서 온다.

### 3.3 3단계: 수식어와 작은 말들 (16–18, 24–26, 28장)

- 상관문 ya-ta (16장)
- 불변화사 ca, vā, hi, eva, pana, api 등 (17장, 부록 F)
- 형용사 비교 "더 ~한 / 가장 ~한" (18장)
- 기타 대명사 (24장)
- 수사: 기수와 서수 (25장)
- 접미 불변화사: 장소·시간·방식을 나타내는 말 (26장)
- 부사와 반복 표현 (28장)

### 3.4 4단계: 동사의 시제와 법 (10, 19–23, 36–37장)

| 형태 | 먼저 잡을 뜻 | 교재 |
|---|---|---|
| present | 한다 / 하고 있다 | 10장 |
| aorist / past | 했다 | 19장 |
| future | 할 것이다 | 20장 |
| imperative | 하라 / 하십시오 | 21장 |
| optative | 해야 한다 / 하면 좋겠다 / 할 수 있다 | 22장 |
| conditional | 만약 …라면 / …했을 것이다 | 23장 |

36장(동사 부류 요약)은 위 시제·법과 perfect·imperfect를 전통 명칭(vattamānā, pañcamī, sattamī, parokkhā, hiyyattanī, ajjatanī, bhavissanti, kālātipatti)과 함께 정리한다. 37장(동사 형성 원리)은 능동·사역·수동형과 중복(reduplication)이 어떻게 만들어지는지 설명한다. 둘 다 부록 C와 함께 참고용으로 본다.

### 3.5 5단계: 문장 연결과 절 구조 (16, 27, 29–31, 35장)

- ya-ta 상관 구조 (16장)
- 의문과 대답 (27장)
- 양보절 "비록 …이지만" (29장)
- 현재분사 (30장)
- 과거분사와 절대분사 (31장)
- iti를 쓰는 직접·간접화법 (35장)

대표 독해 질문

- ya가 무엇을 이끄는가? ta가 앞의 ya와 연결되는가?
- iti 앞의 말이 직접화법인가, 간접화법인가?
- 분사는 어떤 명사를 수식하는가?
- 절대분사는 주동작보다 먼저 일어난 일인가?

### 3.6 6단계: 태와 부정사 (32–34장)

- 수동태, 그리고 수동 의미의 Kita (32장)
- 사역, 그리고 사역 의미의 Kita (33장)
- 부정사와 능력 표현 (34장)

### 3.7 7단계: Sandhi와 Samāsa (부록 D, G)

단어가 사전에 안 나올 때 포기하지 않고 복원한다.

- Sandhi는 소리의 결합이다. 독해에서는 붙은 단어를 다시 나누는 능력이 중요하다.
  - cāhaṃ → ca + ahaṃ
  - tatrāyaṃ → tatra + ayaṃ
- Samāsa는 둘 이상의 말이 한 단어처럼 붙은 것이다. 먼저 가능한 분해를 시도한다.
  - buddhavacana → buddha + vacana
  - dhammavinaya → dhamma + vinaya

### 3.8 8단계: 격 체계 정리와 Kāraka (38장)

격의 의미에 익숙해진 뒤 38장에서 Kāraka(kattu, kamma, karaṇa, sampadāna, apadāna, okāsa)와 vibhatti 용법을 정리한다. 형태(vibhatti)와 문장 속 역할(kāraka)을 구별해서 보는 단계다.

### 3.9 9단계: 실제 문장 독해와 대화 (39장)

- 39장 대화로 지금까지 배운 형태를 실제 말의 흐름 속에서 확인한다.
- 이어서 경전 문장으로 넘어가 아래 4절 Reading Pipeline을 한 문장씩 모두 적용한다.
- 생략된 hoti / atthi 보충, 대명사의 지시 대상, iti의 범위, locative absolute 가능성 등을 확인한다.

### 3.10 10단계: 전통 문법 심화 (부록 A, H, I, J, K)

1. 부록 A: 전통 문법서(Kaccāyana, Moggallāna, Saddanīti 등) 입문
2. 부록 H: Kita (1차 파생)
3. 부록 I: Taddhita (2차 파생)
4. 부록 J: Paccaya 목록
5. 부록 K: 어근 목록

## 4. Reading Pipeline

실제 Pāli 문장을 읽을 때는 다음 순서를 따른다.

### 4.1 1단계: 단어 인식

먼저 문장을 단어 단위로 나눈다.

확인할 것:

- 띄어쓰기 그대로 읽어도 되는가?
- Sandhi 때문에 붙은 말이 있는가?
- 너무 긴 단어가 합성어인가?
- 문장부호가 직접화법이나 인용을 보여주는가?

### 4.2 2단계: 원형 복원

사전에 바로 나오지 않으면 다음을 의심한다.

- Sandhi
- Samāsa
- 격 변화
- 동사 변화
- 분사형
- 불규칙 명사

예:

- cāhaṃ → ca + ahaṃ
- buddhavacanaṃ → buddha + vacanaṃ
- bhikkhussa → bhikkhu + ssa

### 4.3 3단계: 품사 판단

각 단어가 무엇인지 먼저 대략 판단한다.

- 명사인가?
- 형용사인가?
- 대명사인가?
- 동사인가?
- 분사인가?
- 불변화사인가?
- 합성어인가?

처음부터 완벽하게 맞히려 하지 않는다. 먼저 “문장에서 어떤 역할을 할 것 같은가?”를 본다.

### 4.4 4단계: 형태 분석

형태 분석은 독해에 필요한 만큼만 한다.

예:

- bhikkhu → “승려가”
- dhammaṃ → “가르침을”
- suṇāti → “듣는다”

그다음에 필요한 경우:

- bhikkhu: nominative singular
- dhammaṃ: accusative singular
- suṇāti: present, 3rd person singular

### 4.5 5단계: 문장 기능 판단

각 단어가 문장에서 하는 일을 찾는다.

| 기능 | 확인 질문 |
|---|---|
| 주어 | 누가 하는가? |
| 동사 | 무엇을 하는가? |
| 목적어 | 무엇을 당하는가? 무엇을 하는가? |
| 소유 / 관계 | 누구의 것인가? 누구와 관련되는가? |
| 장소 | 어디에 / 어디에서인가? |
| 방향 | 어디로 가는가? |
| 출발점 | 어디에서부터인가? |
| 수단 | 무엇으로 하는가? |
| 동반 | 누구와 함께인가? |
| 목적 | 무엇을 위해서인가? |

### 4.6 6단계: 직역

가능하면 먼저 직역한다.

예:

- bhikkhu dhammaṃ suṇāti.  
  → 승려가 가르침을 듣는다.

- buddhassa sāvako dhammaṃ suṇāti.  
  → Buddha의 제자가 가르침을 듣는다.

### 4.7 7단계: 자연스러운 번역

직역이 어색하면 한국어 문장으로 정리한다.

예:

- 직역: “Buddha의 제자가 dhamma를 듣는다.”
- 자연스러운 번역: “부처님의 제자가 법을 듣는다.”

### 4.8 8단계: 대안 해석 제시

Pāli 문장은 문맥에 따라 둘 이상으로 읽힐 수 있다.

가능성이 있으면 단정하지 말고 대안을 제시한다.

예:

- genitive는 “~의”일 수도 있고, 문맥에 따라 “~에게”에 가까울 수도 있다.
- locative는 “~에”일 수도 있고 “~때에”일 수도 있다.
- optative는 “해야 한다”, “할 수 있다”, “하면 좋겠다”로 갈릴 수 있다.


### 4.9 9단계: 핵심 Dhamma 용어는 PD의 pada nirutti로 뜻을 확인한다

anicca, anatta, saṃsāra, sammā, kusala 같은 핵심 용어는 사전의 한 단어 번역으로 끝내지 않는다. 형태 분석(4.4)으로 문법적 기능을 확인한 뒤, 뜻은 PD의 pada nirutti(12절)로 확인한다.

## 5. Parsing Protocol

형태 분석 질문에는 다음 순서를 따른다.

### 5.1 명사

1. 사전형
2. 어간
3. 성
4. 격
5. 수
6. 의미
7. 문장 기능

예:

- bhikkhussa
  1. 사전형: bhikkhu
  2. 어간: bhikkhu-
  3. 성: 남성
  4. 격: genitive 또는 dative 가능
  5. 수: 단수
  6. 의미: 승려의 / 승려에게
  7. 기능: 소유·관계 또는 대상

### 5.2 형용사

1. 사전형
2. 성
3. 격
4. 수
5. 의미
6. 수식 대상

예:

- mahā
  1. 사전형: mahanta (합성어에서는 mahā- 꼴, 교재 4장 주 3)
  2. 성: 문맥에 따라 판단
  3. 격: 문맥에 따라 판단
  4. 수: 문맥에 따라 판단
  5. 의미: 큰, 위대한
  6. 수식 대상: 뒤따르는 명사 확인

### 5.3 대명사

1. 사전형
2. 종류
3. 격
4. 수
5. 의미

예:

- eso
  1. 사전형: eta / eso 계열
  2. 종류: 지시대명사
  3. 격: nominative
  4. 수: 단수
  5. 의미: 이 사람 / 이것

### 5.4 동사

1. 어근
2. 어간
3. 시제·법
4. 인칭
5. 수
6. 태
7. 의미
8. 기능

예:

- gacchati
  1. 어근: gamu / gam
  2. 어간: gaccha-
  3. 시제·법: present
  4. 인칭: 3인칭
  5. 수: 단수
  6. 태: 능동
  7. 의미: 간다
  8. 기능: 문장의 중심 동사

### 5.5 분사

1. 원동사
2. 분사 종류
3. 성
4. 격
5. 수
6. 의미
7. 수식 대상 또는 문장 기능

예:

- gacchanto
  1. 원동사: gacchati
  2. 분사 종류: present participle
  3. 성: 남성
  4. 격: nominative
  5. 수: 단수
  6. 의미: 가는 / 가면서
  7. 기능: 주어를 수식하거나 동작을 설명

### 5.6 합성어

반드시 분해를 시도한다.

예:

- buddhavacana
  - buddha + vacana
  - Buddha의 말씀 / 부처님의 말씀

- dhammavinaya
  - dhamma + vinaya
  - 가르침과 율 / 법과 율

### 5.7 Sandhi

반드시 원형 복원을 시도한다.

예:

- cāhaṃ
  - ca + ahaṃ
  - 그리고 나는

- tatrāyaṃ
  - tatra + ayaṃ
  - 거기에서 이 사람은 / 거기에 이것은

## 6. Parsing Workbook

Parsing Workbook은 단어 지식을 실제 독해 능력으로 바꾸기 위한 훈련 자료이다.

### 6.1 Level 1: 단일 형태 분석

#### 목표

격·수·성 또는 동사 시제·인칭을 빠르게 인식한다.

#### 예시

- buddho
- dhammaṃ
- bhikkhussa
- bhikkhunā
- gāme
- gacchati
- suṇāti
- karissati
- gaccha
- gaccheyya

#### 훈련 질문

1. 사전형은 무엇인가?
2. 뜻은 무엇인가?
3. 문장에서 어떤 기능을 할 수 있는가?
4. 비슷하게 생긴 다른 형태와 혼동 가능성이 있는가?

---

### 6.2 Level 2: 구 분석

#### 목표

수식 관계와 격 관계를 익힌다.

#### 예시

- buddhassa sāvako
- mahā bhikkhu
- dhammaṃ suṇanto
- gāme vasanto
- paññāya passati

#### 훈련 질문

1. 중심 단어는 무엇인가?
2. 어떤 단어가 어떤 단어를 수식하는가?
3. 격은 어떤 의미를 만드는가?
4. 직역하면 어떻게 되는가?
5. 자연스럽게 옮기면 어떻게 되는가?

---

### 6.3 Level 3: 짧은 문장 분석

#### 목표

주어·동사·목적어를 찾고, 기본 문장을 번역한다.

#### 예시

- bhikkhu dhammaṃ suṇāti.
- buddho dhammaṃ deseti.
- sāvako gāmaṃ gacchati.
- puriso gehe vasati.
- kumārā pāṭhasālaṃ gacchatha.

#### 훈련 질문

1. 주어는 무엇인가?
2. 동사는 무엇인가?
3. 목적어가 있는가?
4. 장소·수단·출발점을 나타내는 말이 있는가?
5. 명령문인가, 평서문인가?

---

### 6.4 Level 4: 경전 문장 분석

#### 목표

실제 문장의 불규칙성, 생략, Sandhi, Samāsa, 복수 해석을 다룬다.

#### 필수 훈련 항목

- Sandhi 복원
- 합성어 분해
- 생략된 동사 보충
- 대명사의 지시 대상 찾기
- iti의 범위 찾기
- ya-ta 구조 찾기
- 분사구의 수식 대상 찾기
- 가능한 번역 2개 이상 비교

#### 분석 절차

1. 문장을 단어 단위로 나눈다.
2. 붙은 단어를 복원한다.
3. 합성어를 분해한다.
4. 핵심 동사를 찾는다.
5. 주어와 목적어를 찾는다.
6. 부가 정보를 붙인다.
7. 직역한다.
8. 자연스럽게 번역한다.
9. 애매한 지점을 표시한다.

## 7. When Stuck 진단표

입문자가 막히는 지점은 정규 규칙보다 예외와 변형이다.

문장이 안 읽히면 다음 순서로 점검한다.

### 7.1 단어가 사전에 안 나온다

의심할 것:

1. Sandhi인가?
2. 합성어인가?
3. 격 변화형인가?
4. 동사 변화형인가?
5. 분사형인가?
6. 불규칙 명사인가?

예:

- cāhaṃ → ca + ahaṃ
- buddhavacanaṃ → buddha + vacanaṃ
- bhikkhussa → bhikkhu의 변화형

### 7.2 단어가 너무 길다

의심할 것:

1. Samāsa인가?
2. Upasagga가 붙었는가?
3. 접미 파생어인가?
4. Sandhi와 Samāsa가 함께 있는가?

### 7.3 끝이 이상하다

의심할 것:

1. 격 변화인가?
2. 불규칙 명사인가?
3. 대명사 변화인가?
4. 동사 어미인가?
5. 분사 어미인가?

### 7.4 동사처럼 보이는데 모르겠다

의심할 것:

1. 현재시제인가?
2. aorist인가?
3. 미래시제인가?
4. imperative인가?
5. optative인가?
6. conditional인가?
7. participle인가?
8. absolutive인가?

### 7.5 familiar word인데 형태가 다르다

의심할 것:

1. 불규칙 변화인가?
2. Sandhi로 변했는가?
3. 다른 격인가?
4. 다른 수인가?
5. 명사가 아니라 형용사로 쓰였는가?
6. 동사에서 파생된 말인가?


### 7.6 핵심 용어인데 사전 뜻이 문맥과 맞지 않는다

의심할 것:

1. 사전이 관습적 뜻(conventional meaning) 하나만 실었는가?
2. 그 단어가 어떤 말이 결합해 만들어졌는가? (12절 pada nirutti)
3. 같은 단어가 문맥에 따라 다른 뜻으로 쓰이는가? (예: attā '사람' / atta '쓸모 있는, 실체가 있는')

## 12. PD의 pada nirutti: 문법 분석과 다른 단어 읽기

### 12.1 두 가지 단어 분석

교재가 가르치는 단어 분석과 PD(Pure Dhamma)가 말하는 pada nirutti는 묻는 질문이 다르다.

```
Pāli 단어 분석
├─ 문법 분석 (교재)
│   ├─ 질문: 이 단어는 어떤 형태이고 문장에서 무슨 일을 하는가?
│   ├─ 방법: 어간 + 어미, 성·수·격, 시제·인칭
│   └─ 예: dhammaṃ = dhamma + -ṃ → 대격 단수, 목적어
└─ pada nirutti (PD)
    ├─ 질문: 이 핵심 용어는 어떤 말들이 결합해 생겼고, 그래서 무엇을 뜻하는가?
    ├─ 방법: 단어를 뿌리가 되는 말로 나눠 Dhamma의 뜻을 찾음
    └─ 예: saṃsāra = saṅ + sāra
```

PD는 nirutti를 "핵심어의 기원을 찾는 것, 곧 paṭi, atta 같은 핵심 말을 써서 합성어가 어떻게 만들어졌는지 찾는 것"으로 설명하고, 그 해석은 attha, dhamma, nirutti, paṭibhāna와 맞아야 한다고 말한다.[^pd-dict] 또 핵심 Pāli 단어는 뜻이 압축되어 있어 다른 언어의 한 단어로 옮길 수 없으므로, 단어를 외우기보다 그 단어에 담긴 뜻을 익히라고 한다.[^pd-key]

### 12.2 PD의 pada nirutti 예

| 단어 | PD의 분석 | PD의 뜻 | 사전·관습 번역[^conv] |
|---|---|---|---|
| saṃsāra | saṅ + sāra | "이 세상에 사는 것이 이롭다(sāra)"는 잘못된 믿음 때문에 재생 과정에 갇힘[^pd-san] | 윤회, 떠돎 |
| sammā | saṅ + mā | saṅ을 없애는 것과 관련됨[^pd-list] | 바르게 |
| kusala | ku + sala | ku(kilesa, 악)를 없앰[^pd-kilesa] | 유익한, 착한 |
| anicca | na + icca | 원하는 대로 유지할 수 없음[^pd-glossary] | 무상 |
| anatta | na + atta | 이롭지 않음, 실체·가치가 없음, 통제할 수 없음[^pd-anatta] | 무아 |
| paṭicca samuppāda | paṭi + icca, sama + uppāda | 좋아함(icca)에 묶여 그에 맞는 것이 생겨남[^pd-tilakkhana] | 연기 |
| anāgāmī | na + āgāmī | 욕계로 돌아오지 않는 이[^pd-anatta] | 불환자 |

여기서 saṅ은 "재생 과정을 늘리는 쪽으로 더하는 것"이고, 반대 방향의 khaya는 "덜어 내는 것"이다(rāgakkhaya = rāga + khaya).[^pd-san]

### 12.3 독해에서 두 분석을 함께 쓰는 법

```
경전 문장 한 줄
├─ 1. 문법 분석으로 형태와 기능 확정 (4.1–4.5절)
│     예: sammādiṭṭhi → 합성어, 주격 단수, 주어
├─ 2. 핵심 용어는 pada nirutti로 뜻 확인 (4.9절)
│     예: sammā = saṅ + mā → saṅ을 없애는 쪽의 diṭṭhi
└─ 3. 문맥과 맞는지 다시 확인 (4.8절 대안 해석)
```

주의할 점

- 두 분석은 서로 대신하지 않는다. 문법 분석은 형태와 기능을, pada nirutti는 핵심 용어의 Dhamma적 뜻을 알려 준다.
- pada nirutti는 모든 단어에 적용하는 규칙이 아니라 핵심 용어에 쓰는 해석 방법이다. 일상 어휘(potthaka, gacchati 등)는 문법 분석과 사전으로 충분하다.
- PD도 사전 뜻을 쓸 때는 문맥과 맞는지 반드시 확인하라고 한다.[^pd-dict]
- 같은 철자라도 장단에 따라 뜻이 갈린다. attā(긴 ā)는 관습적으로 '사람'이고, atta(짧은 a)는 '이로운, 실체가 있는'이다.[^pd-anatta] 그래서 IAST 표기가 중요하다(「왜 Pāli는 IAST로 써야 하는가?」 참고).
