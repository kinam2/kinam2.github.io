# 2. 기본 요소 (Nuts and Bolts)

## Pāli 문자 입문

언어를 말하기 전에 먼저 그 기본 구성 요소를 익혀야 합니다. 이 장에서는 Pāli에 쓰이는 문자를 간략히 정리합니다. Pāli는 오래전에 사어가 된 언어이므로 정확한 음가는 결코 알 수 없습니다. 여기 제시하는 발음 안내는 합리적인 재구성일 뿐입니다. 보통 Devanagari로 자모를 나타내는 Sanskrit와 달리, Pāli는 Sinhala, Myanmar, Khmer, Thai 같은 각 지역의 문자를 씁니다. 서양인들이 Pāli를 공부하게 되면서 로마자를 쓰게 되었고, 이 책도 Pāli에 맞춘 현대식 로마자 표기를 씁니다. 영어 알파벳 일부에 구별 부호(diacritical mark) 몇 개를 더한 것입니다.

Pāli 문자는 모음[sara] 8개[^1]와 자음[vyañjana/byañjana] 33개로 나뉩니다. 모음은 다음과 같습니다.

```
a   ā   i   ī   u   ū   e   o
```

짧은 소리와 긴 소리[rassa-dīgha]의 짝이 세 쌍 있습니다. 글자 위의 가로줄(macron)이 긴 소리를 표시합니다. 나머지 둘, e와 o는 보통 길지만 겹자음 앞에서는 짧아질 수 있습니다. 모음의 발음 안내는 표 2.1과 같습니다.[^2]

**표 2.1 Pāli 모음의 발음**

| 모음 | 비슷한 소리 (영어) |
|---|---|
| a | but의 u |
| ā | father의 a |
| i | pin의 i |
| ī | seen의 ee |
| u | foot의 oo |
| ū | food의 oo |
| e | mate의 a |
| o | note의 o |

Pāli 자음을 전형적인 순서로 적으면 다음과 같습니다.

```
k  kh  g  gh  ṅ     c  ch  j  jh  ñ     ṭ  ṭh  ḍ  ḍh  ṇ
t  th  d  dh  n     p  ph  b  bh  m
y  r  l  v  s  h  ḷ  ṃ
```

이 자음들은 입안에서 소리 나는 자리(조음 위치), 무성음인지 유성음인지, 기음(숨을 세게 내뿜는 소리)인지 아닌지에 따라 묶을 수 있습니다. 학자들은 ṃ[^3](niggahīta)을 모음으로 분류합니다. a, i, u의 비음화를 나타내는 기호일 뿐이기 때문입니다.[^4] 그러나 전통 문법가들은 ṃ을 자음으로 셉니다.[^5] 전통적 정의에 따르면 모음은 스스로 소리를 낼 수 있지만[^6] 자음은 그렇지 못하기 때문입니다.[^7] 이 정의를 따르면 ṃ을 자음에 넣는 것이 타당합니다. 다른 자음들은 뒤에 오는 모음에 기대지만, ṃ은 앞의 모음 a, i, u를 따라야만 소리가 납니다. 어느 쪽이든 자음은 모두 스스로는 소리를 내지 못합니다.

자음의 분류는 표 2.2에 정리했습니다. 아래는 표에 담지 못한 내용까지 포함한 설명입니다. 후음(guttural)은 목구멍에서 발음합니다[kaṇṭhaja]. 구개음(palatal)은 혀의 가운데[jivhāmajjha]로 입천장에서 발음합니다[tāluja]. 권설음(retroflex)[^8]은 혀를 말아 올려 입천장 위쪽, 곧 윗니 뒤 잇몸 둔덕의 뒤쪽에 닿게 해서 발음합니다[muddhaja]. 이때 혀끝 가까운 부분[jivhopagga]을 씁니다. 치음(dental)은 혀끝[jivhagga]으로 이에서 발음합니다[dantaja]. 순음(labial)은 입술로 발음합니다[oṭṭhaja]. niggahīta(ṃ)는 코로 발음합니다[nāsika].

**표 2.2 Pāli 자음의 분류**

| 조음 위치 | 무성·무기 | 무성·유기 | 유성·무기 | 유성·유기 | 유성·비음 | 반모음 | 마찰음 | 치찰음(무성) | 비음 | 해당 모음 |
|---|---|---|---|---|---|---|---|---|---|---|
| 후음 (guttural) | k | kh | g | gh | ṅ |  | h |  |  | a, ā, e, o |
| 구개음 (palatal) | c | ch | j | jh | ñ | y |  |  |  | i, ī, e |
| 권설음 (retroflex) | ṭ | ṭh | ḍ | ḍh | ṇ | r, ḷ |  |  |  |  |
| 치음 (dental) | t | th | d | dh | n | l, v |  | s |  |  |
| 순음 (labial) | p | ph | b | bh | m | v |  |  |  | u, ū, o |
| 비음 (nasal) |  |  |  |  |  |  |  |  | ṃ |  |

조음 위치로 분류할 수 있는 처음 25개 자음을 vagga라고 합니다.[^9] niggahīta를 포함한 나머지는 그래서 avagga라고 부릅니다.

대부분의 자음은 한 자리에서 나지만 예외가 있습니다. ṅ, ñ, ṇ, n, m은 위에서 말한 각자의 자리에 더해 코에서도 소리가 나고, v는 치음이면서 순음입니다. 표의 마지막 열은 해당 모음의 조음 위치를 보여 줍니다. e와 o가 두 자리에서 난다는 점이 눈에 띕니다. e는 후음·구개음, o는 후음·순음입니다. 유성음[ghosa]은 성대를 떨면서 내는 소리이고, 무성음[aghosa]은 성대를 떨지 않고 열어 둔 채 내는 소리입니다. 유기음[dhanita]은 'h'를 섞듯 숨을 더 내뿜으며 내는 소리이고, 무기음[sithila]은 그런 숨이 없는 소리입니다. h는 단독으로는 목구멍에서 나지만, ṅ, ñ, ṇ, n, m, y, r, l, v, ḷ와 결합하면 가슴에서 납니다[urasija].[^10] 예: tañhi, tañhā, nhāsā, asumha, muyhate, vulhate, avhito, rūḷhi. s의 쉿소리는 치음이고 무성입니다. Pāli에는 z 같은 유성 쉿소리가 없습니다.

Pāli 자음의 발음 안내는 표 2.3과 같습니다.

**표 2.3 Pāli 자음의 발음**

| 자음 | 비슷한 소리 (영어) |
|---|---|
| k | king의 k |
| g | gun의 g |
| ṅ | sing의 ng |
| c | choose, church의 ch |
| j | jump의 j |
| ñ | minion의 n(y) |
| t, d, n | 영어와 같음 |
| th | t + 숨. thin이나 then의 th가 아님 |
| ṭ, ṭh, ḍ, ḍh, ṇ | 치음과 같되, 혀가 이가 아니라 입천장 위쪽에 닿음 |
| p, b, m | 영어와 같음 |
| ph | p + 숨. phone의 ph가 아님 |
| y, r, l, s, h | 영어와 같음 |
| v | 영어의 w. 단독으로 설 때는 v[^11] |
| ḷ | l과 같되 기음이 섞이고, 혀가 입천장 위쪽에 닿음 |
| -ṃ | sung, sing의 ng (soong) |

## 모음 등급 (Vowel Gradation)

나중에 참조할 수 있도록 관련 주제 하나를 여기 덧붙입니다. 모음 등급[강도]입니다. 세 단계가 있으며 표 2.4에 정리했습니다.[^12]

**표 2.4 모음 등급**

| (zero) | guṇa | vuddhi |
|---|---|---|
| a | a | a + a = ā |
| i, ī, y | a + i/y = ay 또는 ĕ | a + a + i/y = āy 또는 e |
| u, ū, v | a + u/v = av 또는 ŏ | a + a + u/v = āv 또는 o |

지금 이해가 안 되면 일단 넘어가도 됩니다. 관련 주제에 이르면 쓸모를 알게 됩니다. 표에서 더하기(+)는 두 모음이 만나는 것을 뜻합니다. 순서와는 관계없으므로 a가 i를 만나든 i가 a를 만나든 같습니다. 빗금(/)은 여기서 '또는'을 뜻합니다. guṇa 단계의 ĕ와 ŏ는 짧은 소리를 나타냅니다. 실제로는 이 짧은 소리와 긴 소리의 차이가 크지 않아서, 보통은 짧은 소리 표기를 쓰지 않습니다.

앞에서 보았듯이 y와 v는 각각 i와 u라는 특정 모음과 비슷하게 소리 나므로 '반모음'이라고 부릅니다. 단어 결합(Sandhi, 부록 D)을 배우면 이 반모음과 그에 대응하는 모음이 서로 바뀔 수 있음을 보게 됩니다. guṇa 단계는 주로 Sandhi에서 보게 됩니다. 그리고 paccaya[접미사] 처리, 특히 ṇa와 그 계열(예: 부록 I)을 배울 때 vuddhi 단계를 보게 됩니다.
